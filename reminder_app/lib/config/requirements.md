# Requirements TaskZilla

**Penanggung jawab:** Alya

## 1. Deskripsi
TaskZilla adalah aplikasi mobile untuk membantu mahasiswa mengelola tugas kuliah, mengatur tenggat waktu, dan memantau status pengerjaan tugas.

## 2. Kebutuhan Fungsional
- Pengguna dapat melakukan login dan registrasi.
- Pengguna dapat melihat dashboard.
- Pengguna dapat menambahkan, mengedit, dan melihat detail tugas.
- Aplikasi menyediakan fitur notifikasi.
- Aplikasi menyediakan riwayat tugas dan profil pengguna setelah kedua halaman selesai dibuat.

## 3. Kebutuhan Antarmuka
- Menggunakan Flutter.
- Menggunakan warna utama teal.
- Mendukung tema terang dan gelap.
- Memiliki navigasi ant halaman melalui `app_routes.dart`.
- Menggunakan konfigurasi tema dari `app_theme.dart`.

## 4. Konfigurasi Fitur
Pengaturan fitur disimpan dalam `feature_flags.dart`. Fitur yang belum selesai dapat tetap dinonaktifkan sampai implementasinya tersedia.

## 5. Catatan Pengembangan
Dokumentasi ini digunakan sebagai acuan pengembangan dan pengujian aplikasi TaskZilla.
